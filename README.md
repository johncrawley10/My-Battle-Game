# Python Battle Game

A text-based battle game created as a first-week bootcamp project.

## What I practiced

- Python variables and simple state tracking
- Loops and conditional logic
- User input and basic validation
- Converting values for readable command-line output

## Run it

```bash
python battlegame.py
```

Choose a Wizard, Elf, Human, or Orc, then the program simulates turn-based combat against a dragon.

## Portfolio context

This is an early Python learning artifact. It is included to show programming fundamentals that support later security automation and log-processing projects; it is not presented as a cybersecurity tool.
